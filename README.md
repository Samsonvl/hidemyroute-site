# hidemyroute-site

Публичные страницы сайта **hidemyroute.com** (гайды и инструкции).

Файлы из папки `pages/` автоматически публикуются на сайт: сервер раз в минуту
подтягивает изменения из этого репозитория и кладёт страницы в приложение
hidemyroute.com, после чего делает graceful-перезагрузку (без простоя).

## Как опубликовать правку (с любого устройства)
1. Измени или добавь `.html` в папке `pages/` — можно прямо в веб-интерфейсе
   GitHub с телефона (кнопка ✏️ на файле → Commit).
2. В течение ~1 минуты изменения появятся на сайте.
